To create a static nested class, you add a class as part of another class's body, making it static. This lets you access it via the class name, like other static variables. But this nested static class has access to all the outer classes' private members, and vice versa. Using a nested class for this comparator, I was able to keep my attributes encapsulated, without needing to provide getter methods for each one.
