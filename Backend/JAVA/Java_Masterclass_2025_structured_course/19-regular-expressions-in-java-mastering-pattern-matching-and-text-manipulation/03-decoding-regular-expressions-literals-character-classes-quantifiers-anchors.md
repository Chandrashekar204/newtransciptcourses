I'm going to next add some quantifiers to these patterns but first let me show the options we can use. There are six different quantifiers you can use in your regular expressions. The asterisk quantifier matches zero or more occurrences of the preceding element. For example, b asterisk, matches zero or more occurrences of the letter b, such that an empty string, a single b, two bees or three and so on will all match. The plus quantifier matches one or more occurrences of the preceding element.

For example, b plus matches one or more occurrences of the letter b, so these are the same matches as the b asterisk, but it won't match on none. There must be at least one b to match. The question mark quantifier matches zero or one occurrence of the preceding element. For example, the pattern shown in this table, matches both 'color' and 'colour' that contains the letter u. The letter u is optional, so this quantifier allows for flexibility in matching variations in spelling.

The curly braces quantifier allows you to specify an exact number of occurrences of the preceding element, or a range. For example, b with 3 in curly braces, matches exactly three occurrences of the letter b. If I include a comma after the number specified, b with 2 in curly braces, followed by a comma, this means there must be at least 2 bees in any text for it to be a match. If you include two numbers in the curly braces, you're really specifying a lower and upper range.

In the example here, I specify b, then 3, comma 4, in curly braces. Any text that contains a minimum of three bees, or a maximum of four contiguous b letters, will match this pattern.
