# 9.1 — Stack: Reverse String

> Section 9: <> S&Q: Interview / LeetCode Exercises

In this video, we're going to learn how to use a stack to reverse a string. And the string is going to be word. We'll just reverse the word. And the way we do this is we iterate over the string with a loop and then start pushing these letters onto the stack like this. Then we create a new string and start popping these letters and adding them to that new string. And then we pop the next letter and the next one, and so on. And that's how we use a stack to reverse a string.
