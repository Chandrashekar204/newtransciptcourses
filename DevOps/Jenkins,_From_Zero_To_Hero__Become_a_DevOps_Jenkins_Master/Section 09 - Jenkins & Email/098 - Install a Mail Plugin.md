*Section: Jenkins & Email*

Instructor: Hello and welcome back. In this video, we're going to learn how to install a mail plugin. If you remember at the beginning when we were setting up our installation of Jenkins you click on a button that said something like, install suggested plugins. And if you look for Available, the plugin that we're going to look for is called Mailer. If you look Available, no plugin Mailer is available. But if you go to Installed, let's look for Mailer. And you have your Mailer plugin installed in here. So if you don't find your plugin on the Installed section probably you didn't install it at the beginning. So please go ahead to Available and install it from there.
