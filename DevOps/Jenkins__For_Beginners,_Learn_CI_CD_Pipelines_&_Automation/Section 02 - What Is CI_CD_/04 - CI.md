34 And then what we can do, as part of the CI process, 35 is then go ahead and test as well. 36 So we can use Jenkins to set up a pipeline step 37 to go ahead and test what we've built. 38 So now the key part of this 39 is we're now automating this process. 40 As far as the developer's concerned, 41 he'll commit his change, 42 we'll now start building, and then we can test. 43 And this is the continuous integration part, 44 because if a test fails, 45 the developer knows he needs to commit a change 46 to get the test to pass.
