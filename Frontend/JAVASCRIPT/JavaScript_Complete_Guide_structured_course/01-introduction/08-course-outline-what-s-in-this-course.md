# 1.8 — Course Outline - What's In This Course?

> Section 1: Introduction

So we saw some Javascript in action, we have the basic definition out of the way and hopefully now have a basic understanding of what Javascript is and what this language is all about. Now what's in this course though, what will you learn in this course? You could split this course in two three main blocks I would say - the core basics which you have to know under all circumstances, then the next block where we build up on these basics and build a really strong foundation, you could therefore still call that basics but these would be the advanced basics and then we have advanced concepts which allow you to get to the next level of Javascript development and become a really good Javascript developer.

Now in the core basics block, we get started, this is this module, we learned the core basics about Javascript and its history and so on but once we're finished with this module, we'll dive into all the core syntax, the language basics, into variables, functions, what all of that is, all these core things that make up the Javascript language which you have to know no matter in which environment you want to execute Javascript. We'll dive into efficient development and debugging, how to configure your environment correctly, how to fix errors and how to find them.

We'll dive into control structures, if statements, loops so that you can execute code multiple times based on some conditions. We'll look behind the scenes of Javascript, we'll see what the Javascript engine does in detail. We'll have a close look at functions, a very important concept as it will turn out. We'll have a look at the DOM basics, DOM stands for Document Object Model and this will all be about manipulating the web page we're running on, adding content, removing content and so on.

We'll have a look at arrays and iterables, so at lists of data and how we can work with those. We'll have a look at objects which are super important data structures in Javascript and once we're done with that, you will have a solid basic understanding of the Javascript core syntax and the core features. Now thereafter, we'll build a stronger foundation and if you already know all the core based syntax, this of course might be a great entry point.

You'll find a module, in the curriculum if you check that, about classes and object oriented programming which takes object usage, you learned about objects in the core basics, to the next level. You learned about constructor functions and prototypes, important core concepts baked into the Javascript language. We'll dive deeper into the DOM and how to work with the browser and tap into certain browser features. We'll dive deeper into events, how we can react to mouse clicks and so on.

We'll have a look at functions again, we'll dive really deep into functions and learn about things like recursion and more advanced function usage. We'll explore the number and string types in greater detail and which restrictions we have there and what we can do there. We'll dive into asynchronous code which will be related to that single threading I mentioned and how we can run longer taking operations without freezing our web page. We'll dive into these background HTTP requests, also sometimes referred to as Ajax which I mentioned earlier, which allow us to exchange data behind the scenes without reloading the page and once we did all of that, we will have a very solid foundation, not just the basic core syntax but we'll also know all the important parts of the Javascript language and of using Javascript in the browser.

Now of course then we'll also dive into more advanced concepts, you will learn how to work with third party libraries, how to utilize the Javascript modules and split your code efficiently across multiple files. We'll dive into tooling which allows us to optimize our Javascript code, namely webpack and Babel. We'll briefly dive into browser storage and how you can store data in the browser, we'll have a look at browser support and how you can ensure that your scripts run in all browsers where they need to run, no matter which browsers your end users are going to use.

We'll have a look at Javascript frameworks and there we'll have a look at the React.js library. We'll have a look at meta programming, how you can write code which is easier to use by other developers, really advanced but really important. We'll have a look at Node.js and see how that differs from browser side Javascript and what will be the same. We'll have a look at security and how you secure your code and which security holes you want to avoid.

We'll of course also see how you get your code from your local machine onto a server where other users can use it. We'll have a look at performance optimizations and fixing memory leaks to ship the best possible code and much more. This course is a big course, it has a lot of hours of content because it's simply packed with content. You can simply go from it, from lecture 1 to the last lecture or of course also dive into the modules which are most interesting to you.

I did my best to build the course in a way that allows you to also use it as a reference, so that you don't always have to restart at the beginning if you are coming back to it after a year or so but that you can dive into the sections which are most interesting to you, though if you are new or relatively new to Javascript, my strong recommendation is that you start with lecture one and section one and you go through the course step-by-step, maybe just speeding up playback if I'm going through some concepts you already know.

So this is what's in the course and how you can take it.
