# 4.9 — Beyond true/ false: "Truthy" and "Falsy" Values

Now in Javascript, you also have a concept which is called falsy and truthy values. Now we learned about false and true which were these boolean values, now what's falsy and truthy, is this kind of a strange, special extra data type? No, it's actually just how Javascript under the hood evaluates conditions. Generally, Javascript conditions work with booleans, true or false but they also work with these falsy or truthy values, here's an example. Let's say you have a constant name input which holds a value of Max, here it's hardcoded into the code but of course that could be fetched from an input field on the web page let's say and then we use this in a condition where I compare the value in name input to the hardcoded value of Max, well we know that name input stores Max and therefore this of course would work, to be precise this condition yields true in this example here, so it yields a boolean value and therefore this of course works, that's what we saw thus far.

Now consider this code snippet here. We again have name input which holds Max, in this case hardcoded but could be fetch from the input field on a web page but now in the if condition, I don't compare name and put to any concrete value, I just have if name input here and this name input constant here of course holds a string, not a boolean, right? We initialize it one line above it, so this holds a string, not a boolean and still this works and this works because Javascript tries to coerce values to a boolean value if a boolean is required as it is the case in an if statement. So yes, if statements work with booleans but Javascript tries to convert a value to a boolean if it doesn't get a boolean comparison and also not a boolean itself.

So for example, if you have a variable which you pass into an if condition which you don't compare to anything but you just say if that variable and that variable holds a value of zero, then this will actually be treated as false, so zero is treated as false in a condition. Any other number, including negative numbers on the other hand are treated as true, so zero is kind of a special case which Javascript treats as false. Now when might this come in handy?

Let's say you're doing some division and you don't want to divide by zero. Now let's say the value is provided by the user, the user enters a value in the input and you want to make sure that you don't divide by zero. Of course you could check if user input is equal to zero and if it is, you return or you just use that shortcut of just plugging in the variable name and actually again, our calculator is a great example. It actually never makes sense in our calculator if the user enters 0 here - adding 0, subtracting 0 or multiplying or dividing by zero doesn't really make sense, you could say multiplying resets it but let's say we don't want to have that case and dividing would even be illegal, it's not allowed to divide by zero.

So what we could do in the calculator here, in the calculate result function, besides checking our cases here, we could also make sure that we return if and now we can actually use the or operator here if the entered number and for that, we just have to extract it before we run that code here. So if the entered number here is equal to zero, of course we could do that. What this would now do is it means we would return right away if either the calculation type is not add, not subtract, not multiply and not divide or if the entered number is zero, so let's test this. If we reload this page, of course everything works here but if I enter a zero here, you'll see our output doesn't change down there, so that works.

Now again we can do that but we can also say if entered number or to be precise, since this would be treated as true, if it's anything but zero, we can add an exclamation mark in front of this. Now this might look strange at first but what this says is if not entered number. You might remember that slide at the very bottom here, the exclamation mark operator, that's what we're using here. This negates a value and checks if it's not true. So in this case, entered number if it's 0 is treated as false by Javascript, it's falsy and therefore by adding an exclamation mark in front of it, we kind of invert that value, we say if that's not the case, then we want to make it in here.

Now since zero if the user entered zero is treated as false, this means if not false which is true, then execute this code. So if entered number is a falsy value, then not falsy will return true and if we return true here, well then we make it into this if block and therefore we return from this function and we don't execute the function. If entered number is any other number but zero including negative numbers, then it's truthy and then with the exclamation mark in front of it, it's converted to false, so if false will never execute the code in there right because this code only executes if this first condition is true and therefore we don't make it in here and we don't skip function execution by returning early.

This is how this works and this is the idea behind the truthy and falsy values, you don't always have to make an explicit comparison with the equal or greater than operators, you can also just throw in the variable or the value which you're interested in and then just take this as a condition itself and if it doesn't hold true or false, Javascript tries to convert it to true or false and there, zero is treated as false, any other number is treated as true. Now for strings, an empty string is treated as false, any other string is treated as true and for objects and arrays, it's important to understand that all objects and arrays, even empty ones are always treated as true.

So an empty object is not treated as false, it's always treated as true no matter if there is data in it or not. Null, undefined and not a number by the way are always treated as false. So these are the truthy and falsy values you can keep in mind, you can take that slide, it's attached and kind of print it out and put it next to your desk, these are the special cases in Javascript if you just throw in a single value or just a variable with a value in it into an if condition without a comparison operator, so without the equal sign or the greater than operator, so just the variable like this, then Javascript will look into the variable or look into the value and if it's not true or false already, it will try to convert it to true or false and this is how it then does it.
