It's not like a traditional coordinate system where the y-axis would go from bottom to top and x from left to right at the bottom but instead it's all starting in the top left corner and that makes sense if you consider how a web page is rendered, it's rendered from top to bottom, not built up from bottom to top.

This coordinate system also thinks in pixels and therefore in the top left corner, we would have the coordinate 0 0, x has a value of 0 and y has a value of 0.
