# 34.1 — Module Introduction

> Section 34: Bonus: TypeScript Introduction

In this course, you learned a lot about Javascript. Now what if I were to tell you that there is another programming language, closely related to Javascript, which is also worth knowing and that is Typescript. Now don't worry it's not a brand new language you have to learn, instead Typescript is a language which does not run in browsers, which does not run in Node.js, so it's not like Javascript when it comes to that but instead it's a language which builds up on Javascript, which has to be compiled down to Javascript with help of a tool which we're going to install and which adds new features to Javascript to make Javascript development easier, maybe more fun but definitely also cleaner and helps you write cleaner code.

So in this module, we'll have a look at what exactly Typescript is and how it works, how you can use it and how it looks like and you will then also see why you might want to use it, how to write Typescript code, that it's not that different compared to Javascript and how you can utilize it for your projects.
