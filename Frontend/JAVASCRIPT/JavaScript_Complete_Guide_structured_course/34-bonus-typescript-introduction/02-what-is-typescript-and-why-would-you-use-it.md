# 34.2 — What is TypeScript and Why would you use it?

> Section 34: Bonus: TypeScript Introduction

So what exactly is Typescript, that's important to understand right because without knowing that, it will be hard to learn it and to use it. Now it's important to understand and I really want to stress this, that Typescript is not a brand new language with a totally different syntax, no, it builds up on Javascript, it is a so-called superset to Javascript which in the end means it is Javascript but it adds more features, more syntax features you can use.

Now it is worth noting, as I mentioned, that Typescript does not run in browsers, browsers don't know how to execute Typescript, they know how to execute Javascript. So whilst you will learn how to write Typescript in this module here, it's not a language you can use like this in browsers, instead and that's of course also something you learn in this module, we need an extra tool which compiles Typescript code to Javascript code, so which converts the code to Javascript so that we have the Javascript code we learned about but during development when we write Typescript code, we have a better experience because of all these extra features.

Now speaking of that, which features does Typescript add? Well most importantly the thing that gives Typescript its name, it adds types and with that, I mean data types. Now of course in Javascript, we also know types, you learned about the core types Javascript has - strings, numbers, boolean, objects and so on. Now it is important to understand that Javascript is a dynamic, weakly typed language which means that types are evaluated during runtime, so when your script executes but they're not something you define when you write your code, of course you might know that here you're working with a string and in another place you're working with a number but you're not putting that into your code and let me give you an example where this might matter. Consider this simple add function which adds two numbers, presumably at least but now let's say you're calling this function with two strings which you're passing in, please notice the quotes around the numbers.

Now of course you might wonder why you would do that but consider that this is coming from an input field in your DOM, in your web page, what you get from there will always be a string so even if the user enters a number there, it's technically will be a string. Now if you add these two strings here, you will actually find a bug in your application. It will not crash or show an error but what you will get is basically the concatenated strings and I can quickly show this to you here in the normal Javascript console in a browser, if I add five plus three, we get 53 as a string because it simply concatenates those instead of adding them.

Now that's probably undesired and in Typescript, you can avoid this because in Typescript, you can add types and this is now a syntax feature which is added by Typescript, which does not exist in Javascript. Notice the colons after a and b in the parameter list of the function and after the colon you see the word number. This is Typescript syntax which in the end tells Typescript that both a and b in this case here should be of type number, so we must only call this function with two numbers being fed in, not with two strings.

So here in Typescript, when we compile this to Javascript, I mentioned that it needs to be compiled, we will get a compile time error, giving us as a developer a chance of fixing this before we even test it in the browser so we can catch errors or bugs like this way earlier and that's the huge thing about Typescript or one of the huge things. Now besides adding types, Typescript also adds some other nice features which don't exist like this in Javascript, of course these features since Typescript doesn't run in browsers are always compiled down to Javascript workarounds to make the same feature work there as well but in Typescript, it's often easier to implement certain things thanks to these extra features and in addition, Typescript also compilers next generation Javascript code to old generation Javascript code you could say.

So the thing Babel does, the tool we learned about in the browser support module, Typescript actually has this built in. Typescript also allows you to write modern Javascript Typescript code in the Typescript files and as a result, get Javascript files which will run in older browsers as well. So Typescript sounds pretty interesting to me, let's take a closer look at it, let's see how we install that compiler and let's write some Typescript code.
