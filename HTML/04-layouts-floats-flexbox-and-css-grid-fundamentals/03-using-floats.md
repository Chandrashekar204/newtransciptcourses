But for now, just to finish, let's quickly review how floats work and compare them to absolute positioning. Now, floats are actually not a positioning scheme like absolute positioning but they are still another way in which elements can be out of flow.

And so it actually makes sense to compare it with absolute positioning. So we can achieve a floating element by using float: left or float: right just as we we learned before. And as I was just saying, when an element is floated, it is removed out of the normal flow. And so in this regard, it is exactly the same as with absolute positioning. Now, what's different about floats is that floated elements do still have an impact on surrounding elements.

So text and inline elements will actually wrap around the floated element. And so again, in this regard, floated elements are completely different from absolutely positioned elements, which have no impact and are also not impacted by any of the surrounding elements. Finally, one important characteristic of floats is that the container element will simply not adjust its height to the floated element. And so this is exactly the reason why in the last example that we just saw, we saw that that container element collapsed its height.
