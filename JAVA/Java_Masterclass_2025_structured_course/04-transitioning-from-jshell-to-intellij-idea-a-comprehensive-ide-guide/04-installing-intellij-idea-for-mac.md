Kind: captions Language: en For this course, we're going to use an IDE called IntelliJ IDEA. An IDE, or Integrated Development Environment, is the tool that we use to write programs. The main feature is a text editor, that we type our code into. But an IDE also compiles and runs our programs for us. And as you'll see, it also warns us about errors in our code, before we run it. The IDE we're going to use is called IntelliJ IDEA, created by a company called JetBrains.

There are other IDEs available, and you can use any that you want for this course. If you've already got an IDE that you like, and you're comfortable using, then it's fine to continue using it. Most modern IDEs provide the same, or very similar, features. If you haven't used an IDE before, I suggest you use IntelliJ IDEA. That way your environment will work the same way as you'll see in the videos. A reminder, that this video is for Mac. It's time to download and install IntelliJ IDEA. Lets visit jetbrains.com in a browser. The first time you visit this site you'll probably be asked to accept cookies – the usual thing that many websites now ask, especially if you live in the European Union. You can accept the cookies, or just click the Close button to close the dialogue. Alright, click Developer tools at the top of the page, and then click IntelliJ IDEA. Once that page has loaded click Download.

Make sure Mac OS is selected here, at the top, and use the drop-down to select the correct version for your Mac. There are installers available for Apple silicon or Intel processors. My Mac has an M4 chip so I'll select Apple Silicon, but you would choose the other option if your Mac has an Intel CPU. All new mac computers manufactured since 2020 are Apple Silicon based, so unless you have a very old Mac, use the Apple Silicon option. If you choose the wrong version for your computer, you will get an error when you go to do the install.

If that happens, come back to this page and download and install the other version. Click Allow to allow downloads from the JetBrains site, and the download will start. Alright I've started the download, and I'll come back once its done, so we can install it. The download is now complete, so let's install it by clicking here to see the installer file in Finder. Once it's copied into Applications, you can close the Finder window, and also find IntelliJ IDEA and eject it. You'll now have an icon for IntelliJ IDEA in your launchpad, and that's the installation finished. I'll go into Applications to check that it has installed. To start IntelliJ IDEA you can go through the Launchpad, but as I'm already in Applications I'll double-click it from here.
