# 11.1 — Abstraction & Generalization: Less Code, More Extensibility

> Section 11: Mastering Abstraction & Interfaces: Expand Polymorphism & Java Hierarchies

Kind: captions Language: en In this section, I'll be talking about abstraction and generalization. These concepts, in action, reduce the amount of code you have to write and encourage extensible and flexible code. When I say code is extensible, I mean it can support future enhancements and changes, with little or no effort. An extensible application is designed with change in mind. In this section of the course, we'll be looking at Java's support for these two concepts.
