I get my students in reverse gpa order. Let me summarize the differences between these interfaces. Comparable's method is compareTo and takes a single argument, that will get compared to the current instance. Comparator's method is compare and takes two arguments, of the same type, to be compared to each other.

Comparable's compareTo method is called from an instance that implements Comparable. Comparator's compare method compares objects that don't require them to implement Comparator. Arrays.sort with a single argument requires the array elements to implement Comparable. Arrays.sort with two arguments, does not require the array elements to implement Comparable, but will use the Comparator passed to sort the elements. It's considered best practice for a natural order sort, if Comparable's method returns zero, when the instance's equals method is true for the same argument passed.

Comparator allows for a variety of different ways to sort objects.
