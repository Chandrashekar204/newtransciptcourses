The server socket class is built on Java's traditional IO mechanisms and I've demonstrated how this causes threads to block. You'll maybe remember that java introduced N IO that is non-blocking IO.

I covered quite a few aspects of N IO in an earlier section of this course but only briefly mentioned channels. Rather than using server socket and socket, I can use N IO types, the server socket channel and socket channel. This is the preferred approach for servers that have to handle high volumes of concurrent connections. Because of the channel's non-blocking nature, your server will be able to achieve superior scalability and efficiency. On the flip side N IO introduces a lot more complexity which is the trade off.
