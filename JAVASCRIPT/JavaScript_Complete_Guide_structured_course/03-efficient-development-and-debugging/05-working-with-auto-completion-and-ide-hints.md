> Section 3: Efficient Development & Debugging

Now all the shortcuts don't help you if you write bad or incorrect code but here again modern IDEs or editors like Visual Studio Code have you covered, you get a lot of autocomplete here. Let's say here, with our create and write output method, if I want to use this method, let's say I would want to call it here, I can type create and write or just create in my case and I get suggestions. I get suggestions of functions or variables that I could use here that basically includes the words create and they don't just have to start with it, they include it anywhere.

It doesn't even have to be one word as you can see with the suggestions down there, all properties or functions that includes the characters I just typed in the right order will be shown here and then the suggestions are narrowed down the more I type. So that's really useful because that allows you to write code quicker, for example here, I can just type create, the IDE intelligently guesses that I probably mean create and write output, otherwise I could select a different option and then all you have to do is tap enter or tap to use that and to complete that word, which of course saves you the hassle of writing it all on your own, so that's much faster. Now in addition, you'll also find a short description of what you are going to use here on the right, here for example you'll see that this is a function, that this is the name and that this function will take a couple of arguments which of course allows you to find out if that is the function you really want to use here.

Some functions and properties, especially the built-in ones even have short descriptions attached to them which you then also find here in the panel on the right to learn more about it and learn more about what this will do for you. So this is very important and really helpful. You'll also get something similar if you for example add a dot after an object or in this case here, after an array which turns out to be an object. So this is another core feature which I would recommend that you use.
