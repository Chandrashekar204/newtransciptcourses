# 4.11 — Setting Up a Bigger Example Project (The "Monster Killer")

> Section 4: Working with Control Structures (if Statements, Loops, Error Handling)

Now to practice all that if statement stuff and the related concepts a bit better, let's work on a new little application, a new little project, a little website here, as before, fully driven by a browser side Javascript so that we can experiment with the things we learned and get a nice visual output for that. Now this is the website, I load it, you'll find it attached, of course again it's made up of an index.html file and of an assets folder, the assets folder holds a scripts folder with an empty app.js file and a vendor.js file which is kind of a black box to us right now, it basically establishes a communication channel you could say between our HTML code and Javascript so that we can manipulate the document we see there, something we will of course learn in great detail later in the course, we're just not entirely there yet so for now we just treat this as a black box that yields us some global variables we can use to listen to button clicks and so on.

The app.js file is where we will write our code and of course we also got some styles here in the app.css file, side note all these styles are optimized for Chrome because I recommend following along with Chrome here, not because Javascript wouldn't work in other browsers but simply especially for the styles now, so that we all always have the same thing on the screen. Now this is what we do have on the screen and what we're building is a little monster killer application.

We got the health of a monster and we got the health of a player, we also got a bonus life, in case our health drops to zero we'll be able to recover one time only. We got four buttons which we can press to attack the monster, to launch a strong attack against the monster, to heal ourselves and also to output some log information about the past rounds. Now that's what we'll work on, right now nothing works because all the logic is of course something we will need to write and maybe you can already see some of the if checks we probably will perform, maybe some related to the buttons, whether we launch a normal or a strong attack but also definitely we'll need to check after each round whether we won or not, so whether the health of the monster and/or the player is below zero and we therefore need to quit the game or stop the game. So that will be some if checks and actually, there will be a couple of other if checks as well because we'll also add a functionality where when we load this page, we actually asked the player how much health monster and player should have, 100 health points, 50, 1000 and we'll need to check whether the value the user entered is a valid value and so on. So there'll be a couple of

places where we need if checks and therefore a couple of places where we can practice the things we learned, so let's dive right in.
