So for loop is created with the for keyword, then with parentheses and then you have these three parts in there. The first part is a part where you initialize things for the loop.

You could run a lot of different code here, basically any expression, so anything but an if statement or another loop can be executed here, you could call a function in here but typically what you do here is you initialize a variable, you could initialize multiple variables but in most loops, you'll need one and that's that helper variable which you change after every iteration to execute code. So here I'll go with the classic example of initializing i to be zero, by the way that should be a variable created with let because it will change in every loop iteration so therefore it's a variable, not a constant, then you have your exit condition which is evaluated before every loop iteration and there we could use that example from the slide with i smaller than three which means the loop body will only run if i is smaller than three which of course is the case initially since i is 0 and then separated by another semicolon, you have the code which you want to execute after every code execution, there you can do whatever you want.

You could also omit this by just having a semicolon and nothing thereafter, side note you can omit every statement here, then you would create an infinite loop, you need the two semicolons here though, now you would have a loop that runs infinitely which is something you should be careful about because that can crash your browser since it clutters up memory and takes away all resources but you could do that, in some rare cases you might need that.
