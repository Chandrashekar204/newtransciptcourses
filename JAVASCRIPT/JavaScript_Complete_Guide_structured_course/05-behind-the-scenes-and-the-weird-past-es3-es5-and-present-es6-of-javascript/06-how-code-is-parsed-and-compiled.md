What is a compiler? Well the interpreter starts executing our script but it does so line-by-line in an optimized way, which means the script execution works but is far from being as fast as possible. To have the best possible performance, you don't just want to interpret the code and basically execute it like this but instead you want to compile it to machine code and hand it off to your machine, to your operating system if you will because that will always be faster and that translation of your interpreted Javascript code to machine code is exactly what the compiler does.
