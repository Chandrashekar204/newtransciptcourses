Now what does reduce do to begin with? Reduce, as the name suggests, reduces an array to a simpler value, for example it can reduce an array of numbers to the sum of these numbers. Now what happens is reduce executes this function on every element in the array, just like map and find did and previous value for the first execution is this initial value which you set here if it's set, otherwise it will be undefined.
