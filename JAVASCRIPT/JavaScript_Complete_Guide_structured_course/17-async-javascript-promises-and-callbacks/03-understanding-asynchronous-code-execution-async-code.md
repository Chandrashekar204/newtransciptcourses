Now the browser however needs a way for it to communicate back to our Javascript code and for that we typically or we often use callback functions. The idea here is that for example on setTimeout, we pass a callback function as a first argument if you remember and that callback function is the function the browser should call once the operation is done so that the browser can kind of step back into our script and execute something there once it's done so that we can have our script continue to run but then we're also able to do something once this longer taking operation is done.
