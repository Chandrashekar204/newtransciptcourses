# 32.1 — Module Introduction

> Section 32: Bonus: Programming Paradigms (Procedural vs Object Oriented vs Functional)

In this module we'll have a look at programming paradigms, what this means and most importantly, three important programming paradigms you could use when writing Javascript code. We'll have a look at procedural, functional and object oriented programming and what that means for you and how code would look like if you followed one of these paradigms. Specifically as I said, we'll first clarify what exactly programming paradigms are before we then have a closer look at procedural, functional and last but not least, object oriented programming.

You already learned the basics you need for all these paradigms throughout this course, now we'll have a look at what exactly such a paradigm is and when you use which.
