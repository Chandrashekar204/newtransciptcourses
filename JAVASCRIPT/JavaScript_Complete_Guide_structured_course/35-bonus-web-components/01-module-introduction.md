# 35.1 — Module Introduction

> Section 35: Bonus: Web Components

In this kind of bonus module, we'll dive into web components and web components will turn out to be an exciting set of technologies actually that allow us to build our own custom HTML elements, yes you heard this right. The idea really is that you can build your own HTML elements with help of certain Javascript technologies. Now in this module, we'll therefore have a look at what exactly web components are, which technologies make up this term, web components. We'll have a look at the basics, at the core concepts we need to understand, what it means to build web components and how we build them and we'll of course also see all of that in practice by building some example components.

Now one important note, this module here actually contains content from my Web Components and Stencil.js course which I released here on Udemy. Now it does not include the entire course of course because I do have a standalone course there and this course has everything you need if you want to learn all about web components and especially also dive into a tool, Stencil.js, which makes writing web components much easier. In this module here, we'll effectively have a look at the basics, we'll have a look at the basics of web components, we'll dive a bit deeper and we'll dive into that more complex web components module of that other course. We'll not have a look at the other parts, Stencil which is a third-party library that makes building web components easier because that would really take it too far away from what the focus of this course is and that of course is Javascript and what we can do with it.

Hence in this module, we'll have that thorough, that very thorough introduction to web components based on the content of that course and by the end of this module, you will therefore be able to build your own web components.
