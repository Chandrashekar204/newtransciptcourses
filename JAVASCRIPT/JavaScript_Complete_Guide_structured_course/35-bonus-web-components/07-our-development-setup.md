For one, you can create so-called autonomous elements, these are basically your own custom elements that don't depend on anything, that are totally independent of existing HTML elements that are built into the browser.

Alternatively, you can also create your own custom elements by extending built-in elements though, like extending the built-in button or the built-in paragraph and that also can be a way of creating custom elements. In this course, we'll mostly build autonomous elements but actually we'll show you both ways of creating your own custom elements, your own web components and I will use the name custom element and web component interchangeably here, so you can build custom HTML tags in both ways and I will show you both ways and both are fine to use depending on what you're building, often you want to have your totally separate custom element though, so this autonomous way is probably the more common way.
