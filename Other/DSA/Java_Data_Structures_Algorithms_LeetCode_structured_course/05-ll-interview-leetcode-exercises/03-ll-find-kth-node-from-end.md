# 5.3 — LL: Find Kth Node From End

> Section 5: <> LL: Interview / LeetCode Exercises

So this next coding exercise is called K-th node from end. And in this case k for the kth part is just going to be a variable. So if we have this linked list and k was one, this would be one from the end. And you would return a pointer to this node. Whereas if k was two you would return a pointer to this node and so on down the line. If k was equal to six, you would return a pointer that does not point to any node. So in this coding exercise, I'm not going to walk through the logic for how to solve this, but I will give you this hint.

You're going to use fast and slow, just like you did in the last two coding exercises. So I want you to think about the logic here. If you had a fast and slow pointer, how you would do this? Now, just like we have seen previously, this linked list does not have a length and you cannot calculate the length. You have to use fast and slow to solve this problem. So see if you can figure out this logic and then code this. And remember you can always look at the hints and the solution explanation if you get stuck.

And that is the coding exercise kth node from the end.
