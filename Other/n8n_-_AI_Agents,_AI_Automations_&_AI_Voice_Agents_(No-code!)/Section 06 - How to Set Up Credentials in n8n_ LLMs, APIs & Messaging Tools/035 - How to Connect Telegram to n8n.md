# How to Connect Telegram to n8n

*Section: How to Set Up Credentials in n8n: LLMs, APIs & Messaging Tools*

This is how you can set up telegram for agents in N810 in just a few minutes. If you are building a agents and automations in N810 and want to use telegram as a communication channel, this guide is for you. First, we need to set up our chatbot in telegram. Check the video description for the link to this page. Once you are here, click on Start Bot. This will open a conversation with bot folder, which you can access via the telegram app or website.

Both work just fine. Next, click start in the bot for the chat. This will display all the available actions. What we need is to create a new bot. You can either click the new bot link or simply type Engelbert in the chat. Now give your bot a name. I will call mine Kate. After that you will need a username for your bot and it must end with the word bot. I will go with Kate. YouTube bot. If the username is already taken, can try something else.

You will receive an API token. Copy this token and store it in a safe place. It's crucial for connecting telegram with N810. Remember, never share your token publicly as I will delete mine after this video. You can now access your bot by clicking the provided link. Click start to initiate a conversation. At this point, your bot doesn't do much. Will set up an end to end connection to handle messages and respond automatically in just a bit.

If you'd like to customize your bot, you can even add an avatar in the bottom of the chart. Click edit, then select Edit Board and upload an image. Now go to your workflow. Click on telegram trigger. Now we want to create a connection from scratch. And paste here the access token you copied earlier. And that's it. We have created a telegram bot and prepared it to connect with an agent in N810.
