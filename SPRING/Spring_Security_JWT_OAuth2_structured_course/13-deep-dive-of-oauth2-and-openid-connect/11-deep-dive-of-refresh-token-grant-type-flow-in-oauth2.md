The purpose of Refresh Grant Type flow is very simple. Whatever access_token that is going to be issued by the auth server to the client application, it is going to have some expiration time.

In this scenario, the access_token, it is going to expire in 86,400 second, which is equal to 24 hours. It is not going to work that way because it is going to be super inconvenient for the end user to enter the credentials every time he visits an website.
