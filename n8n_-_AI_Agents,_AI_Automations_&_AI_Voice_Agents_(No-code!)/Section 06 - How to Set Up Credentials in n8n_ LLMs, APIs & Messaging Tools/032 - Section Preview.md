*Section: How to Set Up Credentials in n8n: LLMs, APIs & Messaging Tools*

Welcome to this section, where we focus on a crucial part of working with agents and automations in any time, setting up credentials and connecting external services. This section is dedicated to helping you integrate the most common tools you will need, like LMS, messaging platforms, and cloud APIs. Connecting to most popular services like Google Apps is usually pretty simple, especially if you are using the cloud subscription.

But some tools like WhatsApp, telegram, and others still require you to manually add API keys even with a paid plan. And in some cases you will need to refresh credentials regularly to keep things working. That's why this section is designed to be your go to reference, and feel free to come back here anytime you are building projects and need to set up or troubleshoot credentials. You will learn how to connect to platforms like OpenAI, Grok and Leipzig, and how to integrate messaging tools like WhatsApp and telegram and more.

We will also cover Google services, which is especially useful if you are self-hosting N810. These tutorials are beginner friendly, but include advanced tips too, so you can build powerful and flexible AI automations and AI agents. Let's get started.
