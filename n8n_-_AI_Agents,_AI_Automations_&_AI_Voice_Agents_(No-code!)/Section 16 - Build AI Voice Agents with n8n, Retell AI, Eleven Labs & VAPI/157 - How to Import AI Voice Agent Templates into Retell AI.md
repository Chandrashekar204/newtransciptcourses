# How to Import AI Voice Agent Templates into Retell AI

*Section: Build AI Voice Agents with n8n, Retell AI, Eleven Labs & VAPI*

In this quick tutorial, I'm going to show you how to import templates into IntelliJ, so you can simply use the templates you provide and build your own AI agents in just a few clicks. However, I strongly recommend building them from scratch as well so you understand how everything works and can modify the solutions to fit your needs. As you already know, this course includes pre-made templates to help you get started faster, so you'll find them in the resources section of each lesson.

Just download the one you want to use, then login to your account and make sure you are in the agents section. Then in the top right corner right here you should see an import button. So just click on it. And you can upload the template file right here. And that's actually it. You have now imported a pre-built voice agent and you are ready to customize it and start testing. So see you in the next lesson.
